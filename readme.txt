САМОДЕЛЬНЫЙ STREAM DECK
Первый прототип на Arduino Nano: кнопка открывает Блокнот Windows

1. Что понадобится
    •	Arduino Nano;
    •	механический свитч с двумя контактами;
    •	два соединительных провода (либо через макетку);
    •	USB-кабель для подключения Arduino к компьютеру;
    •	компьютер с Windows;
    •	Arduino IDE и Python.

2. Подключение кнопки
    Подключи один контакт свитча к цифровому пину D2, а второй — к GND на Arduino Nano. У обычного механического свитча с двумя контактами полярности нет: какой контакт подключить к D2, а какой к GND — неважно.
    Arduino Nano                 Свитч

    D2  ─────────────────────┐
                                [ кнопка ]
    GND ─────────────────────┘
    Дополнительный резистор не нужен: в программе будет включён внутренний подтягивающий резистор Arduino (INPUT_PULLUP). При отпущенной кнопке вход D2 считывается как HIGH, а при нажатой — как LOW.

3. Программа для Arduino
    Открой Arduino IDE, создай новый скетч и вставь код:
    const int buttonPin = 2;

    int buttonState = HIGH;
    int lastButtonState = HIGH;

    void setup() {
        pinMode(buttonPin, INPUT_PULLUP);
        Serial.begin(9600);
    }

    void loop() {
        buttonState = digitalRead(buttonPin);

        if (buttonState == LOW && lastButtonState == HIGH) {
            Serial.println("OPEN_NOTEPAD");
            delay(200);
        }

        lastButtonState = buttonState;
    }

    1.	Подключи Arduino Nano к компьютеру.
    2.	В Arduino IDE выбери плату Arduino Nano и соответствующий COM-порт.
    3.	Нажми Upload («Загрузить»).
    4.	Если IDE попросит выбрать процессор, попробуй сначала ATmega328P; для некоторых Nano-клонов может понадобиться ATmega328P (Old Bootloader).
    Как работает скетч
    Arduino постоянно проверяет состояние D2. Когда кнопка нажимается, плата отправляет по USB строку OPEN_NOTEPAD на скорости 9600 бод. Задержка 200 мс помогает избежать повторного срабатывания от дребезга контактов.

4. Подготовка Python на Windows
    Установи Python, если он ещё не установлен. Затем открой командную строку (CMD) и выполни команду:
    pip install pyserial

5. Программа на Python
    Создай файл с именем streamdeck.py и вставь в него следующий код. В строке COM3 замени номер порта на тот, который показывает Arduino IDE (например, COM4 или COM5).
    import serial
    import subprocess
    import time

    # Замени COM3 на порт своей Arduino
    arduino = serial.Serial('COM3', 9600, timeout=1)

    # Открытие Serial-порта может перезапустить Arduino Nano.
    # Даём плате время загрузиться.
    time.sleep(2)

    print("Stream Deck запущен!")

    while True:
        command = arduino.readline().decode(errors="ignore").strip()

        if command == "OPEN_NOTEPAD":
            print("Открываю Блокнот!")
            subprocess.Popen("notepad.exe")

6. Проверка работы
    1.	Подключи Arduino Nano к компьютеру.
    2.	Закрой Serial Monitor в Arduino IDE: один COM-порт обычно может использовать только одна программа одновременно.
    3.	Открой CMD в папке, где сохранён streamdeck.py, и запусти: python streamdeck.py
    4.	В окне CMD должно появиться сообщение «Stream Deck запущен!».
    5.	Нажми физическую кнопку. Должен открыться Блокнот Windows.

7. Если что-то не работает
    Блокнот не открывается. Проверь, что в Python указан правильный COM-порт, скетч загружен в Arduino, а Serial Monitor закрыт. Убедись, что скрипт запущен и окно CMD остаётся открытым.
    Ошибка «could not open port» или «Access is denied». Вероятно, COM-порт уже занят Arduino IDE или другой программой. Закрой Serial Monitor и повтори запуск скрипта.
    Arduino IDE не загружает скетч. Проверь выбранную плату и порт. Для некоторых плат-клонов Nano требуется вариант процессора ATmega328P (Old Bootloader).
    При нажатии ничего не происходит. Проверь провода: один контакт кнопки должен идти к D2, второй — к GND. Для двухконтактного механического свитча полярность не имеет значения.

8. Как расширить проект
    Когда одна кнопка заработает, можно добавить другие свитчи, подключив их к отдельным цифровым пинам (например, D3, D4, D5). В скетче для каждой кнопки можно отправлять свою команду, а в Python — назначить ей отдельное действие.
    Примеры будущих назначений: открыть браузер, запустить калькулятор, открыть папку или запустить выбранную программу.
    Совет
    Пока не обязательно печатать корпус. Сначала проверь одну кнопку, затем собери прототип на макетной плате с несколькими кнопками. Когда схема и программа будут работать стабильно, можно спроектировать и напечатать корпус.
